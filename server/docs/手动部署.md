# 手动分步部署（不跑一键脚本）

适合想逐步掌控、或一键脚本在你的系统上有兼容问题时。前提：已把包解压到 `/opt/privsrv`，已填好 `conf/privsrv.env` 的 `PRIVSRV_IP`。

```bash
cd /opt/privsrv
set -a; source conf/privsrv.env; set +a     # 把配置导出到当前 shell
```

> 注意：`PRIVSRV_IP` 等关键变量是 systemd 通过 `EnvironmentFile` 注入的；手动在前台跑服务时，
> 用上面 `source` 一次即可（务必确认 `conf/privsrv.env` 里已填好 `PRIVSRV_IP`）。

### 1. 系统依赖

```bash
# Ubuntu / Debian
sudo apt-get update
sudo apt-get install -y python3 python3-pip nodejs nginx openssl
sudo pip3 install flask bcrypt websockets
# CentOS / Rocky
sudo dnf install -y python3 python3-pip nodejs nginx openssl
sudo pip3 install flask bcrypt websockets
```

`node_modules/lz4js/` 已内置，无需 `npm install`。

### 2. 生成证书

```bash
bash scripts/gen_certs.sh
```

产物在 `certs/`：`privsrv-ca.crt`(根CA) / `server.crt|key`(游戏域名) / `admin.crt|key`(后台) / `dot.crt|key`(私人DNS)。
根 CA 同时拷到 `uploads/privsrv-ca.crt`，供手机安装信任。

### 3. 初始化后台密码

```bash
bash scripts/init_admin.sh
# 记下打印出来的随机密码（也在 admin_password.txt）
```

### 4. nginx 配置

```bash
# 标准 nginx
sudo cp conf/nginx/privsrv.conf /etc/nginx/conf.d/privsrv.conf
sudo nginx -t && sudo systemctl reload nginx

# 宝塔面板
sudo cp conf/nginx/privsrv.conf /www/server/panel/vhost/nginx/privsrv.conf
# 确认主配置 http{} 里 include 了 vhost 目录，然后重载 nginx
```

若 80 端口被其它站点占用 `default_server`，把本配置里的 `listen 80 default_server` 改成 `listen 80` 并给该 server 加对应 `server_name`，或在原默认站点的 `/agent` location 里加 `proxy_pass http://127.0.0.1:8765;`。

### 5. 前台试跑（可选，先验证再交给 systemd）

开 6 个终端，各自：

```bash
cd /opt/privsrv && export PRIVSRV_IP=你的IP
python3 server.py 8443 --http          # 终端1 后端
python3 agentsrv.py                    # 终端2 WS
python3 admin.py                       # 终端3 后台
python3 proxysrv.py 8080               # 终端4 代理
python3 dnssrv.py 53                   # 终端5 DNS
python3 dotsrv.py 853                  # 终端6 DoT
```

另开一个终端跑 `bash scripts/check.sh` 验证。

### 6. 交给 systemd 托管

```bash
sudo cp conf/systemd/*.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable privsrv agentsrv privsrv-admin privsrv-proxy privsrv-dns privsrv-dot
sudo systemctl restart privsrv agentsrv privsrv-admin privsrv-proxy privsrv-dns privsrv-dot
bash scripts/check.sh
```

### 7. 防火墙

放行 `80 443 8080 38443 53 853`(TCP) 与 `53`(UDP)，云服务器另需在控制台安全组放行。

### 8. 手机接入

见 `开服教程.md` 第 4 章（WiFi 代理 / 私人 DNS + 安装根 CA）。
