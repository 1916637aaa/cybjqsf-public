# client/

本目录在本仓库中**只保留研究工具**，不含原版客户端安装包与解密源码。

| 内容 | 是否在本仓库 | 说明 |
| :--- | :--- | :--- |
| `tools/` | 是 | 解包、参数化重打包、签名、校验脚本 |
| `base/` | **否** | 原版安装包属第三方版权内容，请自行持有 |
| `src/` | **否** | 解密后的源码与资源，属逆向产出，不在本仓库分发 |
| `hotfix/` | **否** | 基于原包的热修脚本，属衍生材料 |
| `out/` | 空 | 构建产物输出目录 |

## 使用前提

`tools/` 里的脚本以**固定版本的原版安装包**为输入（v0.8.10）。脚本内置锚点校验与多项断言，
基底版本不符时会直接失败并提示，不会硬改。请先确认你手上的安装包版本一致，再去跑流程。

流程与字段说明见 `docs/01_客户端改动清单.md`，该文档原本针对私有交接包编写，
其中提到的 `client/base/`、`client/src/` 在本仓库中不存在——需要你自己准备对应目录内容。
