# 创游编辑器自建服务端 · 手机接入指南（占位符版）

> 面向设备操作者。所有 `<新服务器IP>` 请替换为 `conf/revive.env` 里 `YOUR_SERVER_IP` 的实际值。
> 本版已把旧服务器 IP 全部移除，适用于任意新服务器。

---

## 需要准备的两个文件

| 文件 | 从哪来 |
|---|---|
| `创游编辑器_复活版_已签名.apk` | 执行 `client/tools/build_revived_apk.py` + `sign_apk.sh` 生成 |
| `privsrv-ca.crt`（根证书） | 服务端 `gen_certs.sh` 生成，在 `/opt/privsrv/certs/` 与 `/opt/privsrv/uploads/` |

用微信/QQ 发给自己，或数据线拷到手机。

---

## 服务端提供的三条接入路

| 服务 | 端口 | 用途 | 说明 |
|---|---|---|---|
| nginx | 443 → 8443 | 自建服务端本体（HTTPS 业务） | 必需 |
| `privsrv-proxy` | 8080 | **HTTP CONNECT 代理** | ✅ **推荐** |
| `privsrv-dns` | UDP 53 | 普通 DNS 劫持 | 可能被运营商劫持 |
| `privsrv-dot` | TCP 853 | 加密 DNS（DoT） | 部分网络 853 不通 |

**推荐走代理**：代理收到 `CONNECT xxx.hortorgames.com:443` 后直接接到本机 nginx，
**全程不解析任何域名**，不受 DNS 劫持、853 封端口影响。

## 操作步骤

### 第 1 步 · 安装 APK
1. **先卸载原版**（签名不同，覆盖必定失败）
2. 点击 APK 安装，提示「未知来源」就授权

### 第 2 步 · 安装根证书
设置 → 搜索「**安装证书**」→ 类型选「**CA 证书**」→ 选 `privsrv-ca.crt`
（⚠️ 别选成「VPN 和应用」）

### 第 3 步 · 私人 DNS 改回「自动」
设置 → 网络与互联网 → 私人 DNS → 选「**自动**」
（若之前没设过 DoT 可跳过；设过却不改回会干扰代理）

### 第 4 步 · 配置代理（关键）

**4A · WiFi 环境**
设置 → WLAN → **长按**当前 WiFi → 修改网络 → 高级选项 → 代理「**手动**」
- 代理主机名：`<新服务器IP>`
- 代理端口：`8080`

**4B · 手机流量（4G/5G）**
蜂窝网络下 Android 不提供系统代理，需要免 root 的本地 VPN 工具（如 **Postern**）：
- 新建代理：类型 **HTTP**，服务器 `<新服务器IP>`，端口 `8080`
- 规则设为**全局**
- 开启 VPN

> VPN 层拦截，App 绕不过去，成功率比系统代理高。

### 第 5 步 · 验证
手机浏览器打开 `https://platform.hortorgames.com/_admin/state`

| 显示 | 含义 |
|---|---|
| `{"uploads":0,"users":N,"works":5}` | ✅ 通了 |
| `no Route matched` | ❌ 代理没生效 |

### 第 6 步 · 打开 APP 登录
- 手机号随便填
- **验证码固定 `1234`**
- QQ / 微信登录已失效（AppId 绑原签名指纹，重签名后必然失效）

## 后台管理面板

浏览器打开 `https://<新服务器IP>:38443`
- 若经代理访问：代理对 38443 有专门直连映射，不会错拐到 443
- 密码在服务器 `/opt/privsrv/admin_password.txt`（安装时现场随机生成）
- ⚠️ 连续输错 5 次会锁 15 分钟（后台自身机制）

## 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 验证页 `no Route matched` | 代理没生效 / App 不走系统代理 | 换 4B 的 VPN 方式 |
| 设代理后其他网页打不开 | 代理只转发 hortor 相关域名 | 正常，不用时把代理改回「无」 |
| 浏览器提示证书不受信 | CA 没装或装错类型 | 重装，类型必须选「CA 证书」 |
| 操作后台弹「下载一个东西」 | 38443 被拐到 443 | 确认代理端口映射含 38443 |
| App 一直转圈 | WS 明文 80 端口 `/agent` 未转发 | 让服务端查 nginx 80 配置 |
| 首页内容区空白 | 客户端补丁未生效 | 用 `verify_apk.py` 检查 4 处补丁标记 |
| 完全上不了网 | 代理填错 | 把代理改回「无」 |

## 进去之后能玩到什么

| 功能 | 状态 |
|---|---|
| 启动、登录、拿到 token | ✅ 完整 `LoginData` |
| 配置 / 公告 / 开关 / 防沉迷 / 心跳 | ✅ 按 SDK 字段名精确实现 |
| 作品列表 / 发布作品 | ✅ 内置 5 个示例作品，真实落库 |
| 信誉分（3 片叶子）、加扣分明细 | ✅ 后台可手动加/扣，需退出重登刷新 |
| 社区 / 素材等长尾接口 | ⚠️ 走兜底（返回合法成功，不崩溃） |

**已知限制**
1. 第三方登录不可用（重签名后指纹不匹配），只能手机号登录
2. 信誉分归零 = 功能全锁 + 全灰叶子，**不会强制退登、不弹「账号被封禁」**（原版客户端无此逻辑）
3. 数据在 `/opt/privsrv/data/db.json`，删掉即恢复初始状态
4. 补兜底接口：在 App 里多翻几个页面，打开 `https://platform.hortorgames.com/_admin/paths`，
   把列出的路径交给服务端补充实现
